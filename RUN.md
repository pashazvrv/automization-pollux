# Прогон очереди экспериментов (атомизация запросов, v5)

Нужно: Linux или macOS, Python 3.10+ (на Ubuntu также `python3-venv`,
на macOS — `xcode-select --install`), git.

## Запуск — одна команда

```bash
LLM_KEY=... LLM_MODEL=... bash run.sh
```

`LLM_KEY` — ключ gigagateway, `LLM_MODEL` — имя модели на гейтвее
(присылаются отдельно от этого файла).

Скрипт `run.sh` один на всё: сам склонирует репозиторий (при повторном
запуске — обновит), создаст окружение, проверит доступ к гейтвею и прогонит
очередь: G0 (дымовой) → G2 (основной) → G4 (стабильность) → G5 (черновики).
После каждого шага — HTML-дашборд, логи — в `results/logs/`.

## В конце

Прислать обратно файл `automization-pollux/results_bundle.tar.gz`.

## Если что-то пошло не так

- Прерывание безопасно: повторный запуск той же команды продолжит с места остановки.
- «Эндпоинты не отвечают» — проверить ключ/имя модели.
- «ГЕЙТ G0 НЕ ПРОЙДЕН» — дальше не гнать, прислать архив и вывод консоли.
- При любой ошибке — прислать текст из консоли и папку `automization-pollux/results/logs/`.

## Варианты запуска (необязательно)

```bash
bash run.sh --only g0     # только дымовой шаг (обязательно первым)
bash run.sh --only g2     # основной (после успешного g0)
bash run.sh --only g4     # стабильность (после g2)
bash run.sh --only g5     # черновики (независим)
bash run.sh --from g2     # продолжить очередь с шага g2
bash run.sh --workers 16  # больше параллелизма
```

Подробности — в `FOR_DANIIL.md` внутри репозитория.
