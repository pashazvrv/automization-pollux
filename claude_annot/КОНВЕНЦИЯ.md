# Согласованная запись задач и ограничений (решение от 03.11.2026)

Задачи и ограничения хранятся ТОЛЬКО в нормализованной форме (не дословные куски запроса).
Контекст (role, data, background) остаётся дословным. Весь материал — в `data`.

## Задача
- Инфинитив + объект: «Выписать три темы текста», «Перевести текст на русский».
- Количество элементов результата — часть задачи: «Придумать семь вопросов…», «Предложить пять идей…».
- Убираются вежливость и рамки: «пожалуйста», «можешь», «помоги», «мне», «нужно», «Задача:».
- Указательные убираются: «этот текст» → «текст»; отсылка восстанавливается («эту теорию» → «теорию цикличности…»).
- Вопрос переводится в действие: «Как называется фильм?» → «Назвать фильм»; «Правда ли, что X?» → «Проверить, правда ли, что X»; загадка → «Отгадать загадку».
- Описание входного материала остаётся в задаче («фрагмент научно-популярной статьи»).

## Ограничение задачи
- Именная группа «признак + объект», с маленькой буквы: «ключевые темы», «текст в стиле Льва Толстого», «функция на C++».
- Запрет — через «без»: «шаурма без капусты», «убеждение без аргументов о вреде мяса».
- Спецификация кода — «входные данные: …», «результат: …», «сложность …».
- Расшифровка шкалы — «шкала: 1 — …, 5 — …»; сама шкала — формат.

## Ограничение формата
- Та же форма «объект + форма»: «пересказ в трёх предложениях», «оценка по шкале от 1 до 5», «текст не менее 2500 знаков».
- Только то, что проверяется программой; к каждому — check.

## Прочее
- «от лица …» — роль (context.role), не ограничение.
- Неделимые (no_task): задач нет, неявная задача — в заметке.

## Атомарность ограничений (решение от 03.11.2026)
Одно ограничение = одно условие, которое проверяется по ответу отдельным вопросом «да/нет»
и может быть нарушено независимо от остальных. Ограничения дробятся до максимума.

1. **И / перечисление → дробим.** Каждый член перечисления — отдельное ограничение, объект повторяется,
   чтобы ограничение читалось само по себе:
   «предложение с «вещной» номинацией, словом с непроизносимой согласной и приложением» →
   «предложение с «вещной» номинацией» · «предложение со словом с непроизносимой согласной» · «предложение с приложением».
2. **Запреты — каждый отдельно:** «без слов на букву Ё» · «без слов на букву Щ» …
3. **Однородные признаки объекта — отдельно:** «чёрно-белые, очень старые, малоизвестные фильмы» →
   «чёрно-белые фильмы» · «очень старые фильмы» · «малоизвестные фильмы».
4. **Код:** каждый входной параметр — «входной параметр: …»; каждое свойство результата и каждая сложность — отдельно.
5. **Не дробим:**
   - **ИЛИ / альтернативы / допущения** — одно условие: «алгоритм со сложностью O(n) или O(n log n)»,
     «зарубежные и отечественные фильмы» (= подходят любые);
   - **«только X, Y и Z»** — один запрет на всё остальное;
   - **расшифровку шкалы** («шкала: 1 — …, 5 — …») и **набор допустимых ответов** — это одно определение;
   - **неразрывное понятие** («эпигенетика собак породы вельш-корги», «железная дорога между Китаем и Россией»,
     «в доме живут муж и жена»): проверить части по отдельности нельзя.
6. Привязка (attach) у всех частей — как у исходного ограничения.
